Personal Expense Tracker

A simple and interactive web application that allows users to track their daily income and expenses. The Personal Expense Tracker helps maintain financial awareness by showing total income, total expenses, and remaining balance in real time. It is built with HTML5, CSS3, and JavaScript (ES6), and uses LocalStorage to save data persistently on the user's device.

🚀 Features

Add income and expense entries

View total income, expenses, and balance

Delete entries anytime

Automatically updates all calculations

Clean and responsive user interface

Data persistence using LocalStorage

Real-time DOM manipulation

Error handling for invalid inputs
